# מחולל הערכת שווי – צוות סרגייב

יוצר מצגת הערכת שווי (9 שקפים, עברית, PDF + PPTX) מקובץ נתונים אחד.

```
python3 make.py spec.json <תיקיית פלט> [<תיקיית ה-skill של pptx>]
```

דרישות: node עם pptxgenjs, react, react-dom, react-icons, sharp; python3 עם Pillow; LibreOffice; pdftoppm.
דוגמה לקובץ נתונים: `example.json`.
